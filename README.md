# Shakk

Online multiplayer Chess game (in progress).

Currently features a playable chess board with pieces and legal move system (local two-player).

## Live Demo

Once GitHub Pages is enabled, visit: https://dompinator.github.io/shakk/

## Features

- Visual chess board
- Unicode pieces
- Legal moves using chess.js
- Click to select and move
- Reset and Undo
- Check, checkmate, and draw detection
